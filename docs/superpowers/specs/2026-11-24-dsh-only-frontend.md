# 快速实现 Spec：Copis 桌面仅保留 DSH 会话前端

范围已确认（2026-11-24）。交付对象是 Electron renderer 与现有 DSH 创造模式客户端插件，而非卸载 Pi。沿用现有 Cordis 页面、插件和 Jotai 状态，不新造一套会话或导航系统。

## 变更边界
- 新装、升级、异常旧值均只进入 DSH 会话前端；公共设置、浏览器等桌面功能仍可打开且能返回 DSH。启动失败展示现有修复/重试入口，不切回标准 Agent。
- 移除可见的模式切换、标准 Agent 欢迎/会话入口。快捷键、标签恢复、插件回退、通知与后台事件不得重新挂载标准 Agent。新建会话走既有 DSH 动作，而非创建隐藏的 Pi 会话。旧 Agent 通知不得误打开同名 DSH 会话。
- 旧 Agent 标签不恢复到前台，但不删除或迁移旧会话、工作区、附件。保留公共标签；过滤活跃旧标签后选择有效页面。保留后台订阅和状态更新，仅去除其强制导航。
- 不改 Rust API、主进程/Preload 协议、Pi Worker、自动化、机器人、CLI、模型超时、依赖或打包配置。不改 AGENTS.md、README.md。不要求删除所有未挂载的旧组件。

## 快速实施
1. Renderer：核对 app-mode、AppShell/MainArea、main 启动/恢复、快捷键、标签与全局监听；在导航归属点统一约束，仅 DSH 是会话目的地。不要只改默认值或用 CSS 隐藏。
2. DSH 插件：核对所有向 host 发起的模式切换及菜单；保留公共功能的真实导航，不用返回旧 Agent 作为兜底。若已有源码与产物同步约定，沿用现有构建命令。
3. 覆盖下列行为后，由主 Agent 审查；不全量回归、不自动截图验收。不覆盖工作区已有媒体和通知改动。

## 验收（BDD）
| Given | When | Then |
|---|---|---|
| 全新配置或旧模式为 agent/未知 | 启动 | 直接显示 DSH，无旧 Agent 页面或切换按钮 |
| 旧 Agent 会话为活动标签，另有公共标签 | 恢复窗口 | 不挂载或新建旧会话；公共标签仍可访问，历史文件不变 |
| DSH 已打开 | 执行新建会话快捷键 | 走现有 DSH 新建行为，不调用旧 Agent 创建接口 |
| 旧 Agent 事件/通知和 DSH 通知分别到达 | 后台更新或用户点击 | 旧事件不抢占页面；DSH 通知仍打开正确 DSH 会话 |
| DSH 未就绪或启动失败 | 打开应用 | 可见现有故障/恢复提示；不回退 Agent，仍可访问设置 |
| 已在设置或浏览器 | 返回会话 | 回到 DSH；公共操作不依赖旧 Agent 页面 |

自动化只跑变更相关用例和受影响的前端构建；最终 UI 与真实快捷键、通知点击由用户在 Electron 窗口验收。交付列出实际运行项、未验证项与遗留限制。
