# Copis Working 登录页设计

日期：2026-08-08
状态：已确认，进入实现

## 目标

将 Copis 当前未登录时的 Working 登录界面从简单的居中认证弹窗升级为 ai-education 风格的双栏登录体验，同时继续使用 Copis 已有的认证 IPC 和本地认证状态。左侧不是静态三栏，而是一个独立的 Landing Page 内容轮播。

## 页面结构

桌面窗口采用左右双栏：

- 左侧为产品展示轮播，占据主要视觉区域。
- 右侧为登录/注册表单，保持紧凑、可扫描、可操作。

左侧轮播包含三张主题，按照 `landingPages` 的内容顺序组织：

1. 顶部 Hero：Copis、本地优先的智能工作台。
2. 中部 AI 浏览器：看见页面，再替用户推进。
3. 底部 Workflow：研究、文件交付、团队与自动化。

任意时刻只展示一张主题。轮播支持自动切换、上一张/下一张、分页指示器；鼠标悬停和键盘聚焦时暂停，`prefers-reduced-motion` 开启时不自动切换。产品视觉摘要使用现有 CSS 构图和 Copis logo，不新增图片依赖。

小窗口下左侧展示区域收缩或隐藏，右侧认证区域保持完整可用；表单不得被固定高度裁切。

## 认证行为

继续复用 `CopisWorkingLoginDialog` 的既有能力：

- 登录/注册模式切换。
- 登录使用用户名或账号 + 密码。
- 注册使用邮箱、密码、可选昵称、可选邀请码；无邀请码时需要邮箱验证码。
- 忘记密码保持邮箱、验证码、新密码三步流程。
- 提交期间禁用相关控件并展示加载状态。
- 错误与成功提示保留在表单上下文中。
- 认证成功后通过 `onAuthenticated(WorkingAuthState)` 进入现有 AppShell，不改变后端或 IPC 合同。

`dismissible={false}` 的全屏入口使用新双栏页面；可关闭的设置登录入口继续保留弹窗语义和关闭按钮。

## BDD 回归场景

```text
Given Copis 尚未完成 Working 登录
When 渲染登录入口
Then 页面显示左右双栏
And 左侧只显示 Landing Page 轮播的当前一张主题
And 右侧显示登录表单

Given 左侧轮播正在显示任意主题
When 点击下一张、上一张或分页指示器
Then 只切换到对应主题
And 当前分页状态与主题一致

Given 用户正在查看左侧轮播
When 鼠标悬停或键盘焦点进入轮播
Then 自动切换暂停
And 离开后恢复自动切换，除非用户启用了减少动态效果

Given 用户在右侧输入有效登录信息
When 提交登录表单成功
Then 通过现有 WorkingAuthState 回调进入应用
And 左侧轮播状态不会阻止认证完成

Given 窗口宽度较小
When 渲染登录页
Then 认证表单仍完整可见、可滚动和可提交
And 左侧展示内容不会遮挡表单
```

## 范围

本次只修改 Renderer 登录入口及其测试/样式，不修改 `README.md`、后端认证接口、IPC 类型或登录凭据存储。现有设置中的可关闭登录弹窗行为保持兼容。
