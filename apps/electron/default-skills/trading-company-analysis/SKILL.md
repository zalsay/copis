# 上市公司基本面与财务三表剖析手册

基于杜邦分析法与现金流贴现（DCF）理念的上市公司深度研报框架。

## 核心剖析步骤

1. **商业模式与护城河（Moat）**
   - **客户与议价能力**：对上游供应商和下游客户的议价权（体现在应收账款与应付账款占比）。
   - **核心壁垒**：特许经营权、专利技术、品牌黏性、网络效应、转换成本或规模成本领先。

2. **财务三表体检（健康度筛查）**
   - **资产负债表（稳健性）**：
     - 有息负债率（短期借款 + 长期借款 / 总资产）；
     - 货币资金充裕度；警惕“存贷双高”（账面巨额现金同时背负大额高成本贷款）。
   - **利润表（盈利质量）**：
     - 毛利率趋势（衡量定价权）与净利率；
     - 核心利润占净利润比重（剔除一次性政府补助或资产处置收益）。
   - **现金流量表（真金白银）**：
     - 经营活动现金流量净额与净利润比值（常年 > 100% 证明利润含金量高）；
     - 自由现金流（FCF = 经营现金流 - 资本开支）。

3. **核心比率与估值**
   - **净资产收益率（ROE）与杜邦分解**：ROE = 净利率 × 总资产周转率 × 权益乘数，甄别高 ROE 来源（是靠高暴利、高周转、还是高杠杆？）。
   - **估值指标匹配**：
     - 稳定盈利企业：PE（TTM）与历史分位数；
     - 重资产周期企业：PB-ROE 框架；
     - 成长型科技/SaaS企业：PS 或 PEG 比率。
