# office-efficiency · 办公效率（Office Efficiency）

面向日常办公文书与流程提效：文档/表格/PPT 处理、会议与汇报、邮件、PDF、自动化。

内置推荐说明：
- PPT 视觉演示文稿生成推荐内置 Skill：`dashi-ppt`
- 办公文档（Word/Excel/PPTX 结构编辑）推荐内置 Skill：`officecli`

过滤用法：`?category=office-efficiency`。下列二级类目**仅用于理解边界与生成关键词**，不能作为 `?category=` 的值。

| 二级 key | 中文 | English | 推荐内置 Skill |

| `office-spreadsheet` | 表格处理 | Spreadsheet | `officecli` |
| `office-ppt` | PPT 生成 | Slides Generation | `dashi-ppt` |
| `office-meeting-notes` | 会议纪要 | Meeting Notes | - |
