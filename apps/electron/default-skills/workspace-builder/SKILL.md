# Workspace Builder (工作台搭建师)

本 Skill 专门指导 Agent 为不同用户群体搭建高颜值、零外部依赖、响应式且支持离线持久化的单文件 HTML 个人工作台。

## 一、核心设计铁律

1. **单文件零依赖（Zero-External-Dependency）**
   - 严禁引入任何外部 CDN、外部框架（Vue/React）或外部字体。
   - 所有 CSS 样式与原生 JS 逻辑必须全部内联。
   - **图表与图标**：图表使用内联 SVG 手写（折线图、柱状图、环形进度条、饼图）；图标采用标准 SVG Path，**禁止使用 Emoji 作为功能图标**。
   - 字体统一使用系统字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`。

2. **双端适配与防缩放**
   - 采用 Flex / Grid 响应式，屏幕宽度 `<768px` 自动变为单列堆叠布局。
   - 触控按钮最小热区 $\ge 44\times 44\text{px}$（儿童向界面 $\ge 50\text{px}$）。
   - 输入框 `font-size` 严禁小于 `16px`（避免 iOS Safari 聚焦时强制缩放视图）。
   - 数字输入框显式指定 `type="number"`。

3. **「今日待办」首屏置顶与顺延**
   - 页面最顶部必须设立「今天要处理」核心区域。
   - 逾期未完成条目标红并提供一键处理按钮。
   - 昨日未打卡/未完成事项自动平滑顺延到今天，不可凭空消失。

4. **数据存储与冷启动保障**
   - 本地持久化以 `localStorage` 为基础，键名添加专属前缀 `wb_{workspaceId}_`。
   - 首屏显式提供「导出 JSON 备份」与「导入恢复」按钮，数据条目达 30 条时展示温和备份提醒。
   - **严禁白屏冷启动**：初始进入必须预置 3~5 条具象业务示例数据（其中 1 条处于逾期状态），并提供“清空示例数据”按钮。

5. **代码架构防无限递归（DAG 准则）**
   - 函数调用关系必须是有向无环图（DAG），严禁渲染函数之间互相调用。
   - 统一使用调度函数 `refreshAll()`：
     ```javascript
     function refreshAll() {
       renderTodaySection();
       renderCalendar();
       renderList();
       renderStats();
     }
     // 事件监听 -> 修改状态 -> 调用 refreshAll()
     ```

## 二、目标人群与模块配置（严格单次选 3-4 个模块）

- **学生 / 备考党**：刷题计数器、错题本（分类/重做标记）、学习计划矩阵、目标倒计时。
- **职场 / 打工人**：任务看板（P0/P1/P2）、周报自动生成器、趋势统计图、会议纪要。
- **自媒体 / 副业**：选题流转看板（灵感→撰写→发布）、素材灵感库、各平台数据复盘。
- **宝妈 / 育儿**：识字卡片（正反翻转）、积分挑战与奖励兑换商城、成长记录。
  - *特别支持*：家长/孩子双模式 Tab 切换，家长模式加设 4 位本地防误触 PIN 码。
- **生活 / 泛管理**：收支记账（红支绿收、¥ 符号）、习惯打卡日历热力图、体重体脂趋势图。

## 三、标准化搭建流程

### 步骤 1：需求聚焦与模块锁定
- 识别目标客群，在 1~2 轮对话内推荐并锁定 3 个核心模块，避免需求膨胀。
- 确认主色调（默认遵循清晰现代的圆角卡片风格，高对比度微阴影）。

### 步骤 2：生成单文件 HTML
- 按照上述铁律编写完整的单文件 HTML 代码（含 HTML 结构、CSS 变量与样式、原生 JS 数据管理与渲染逻辑）。
- 确保包含今日置顶、示例数据、导入导出、内联 SVG 图表。

### 步骤 3：冒烟自检（交付前必须逐条核对）
- [ ] **调用链无环**：确认无函数循环调用。
- [ ] **DOM 绑定安全**：确认在 `DOMContentLoaded` 内完成元素获取与事件挂载。
- [ ] **空数据测试**：清空缓存或首次打开时，数据解析不崩溃。
- [ ] **日期边界**：跨月（如 1月31日 $\rightarrow$ 2月1日）与跨年计算正确。

### 步骤 4：交付与使用指引
- 将 HTML 交付给用户或直接生成文件。
- 提示用户：可在电脑浏览器直接运行；在手机端可通过系统浏览器“分享 $\rightarrow$ 添加到主屏幕”作为全屏轻应用使用；定期使用“导出备份”保存数据。
